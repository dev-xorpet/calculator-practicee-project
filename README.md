# 🧮 Calculator Project

A simple and responsive calculator built using **HTML**, **CSS**, and **JavaScript**.

This project was created as a practice exercise to improve front-end development skills and gain a better understanding of DOM manipulation, event handling, and user interface design.

## ✨ Features

- Basic arithmetic operations:
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)
- Decimal number support
- Delete last input
- Clear all inputs
- Division by zero handling
- Responsive and modern user interface
- Smooth button animations

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and layout
- **JavaScript (ES6)** – Calculator logic and interactions
